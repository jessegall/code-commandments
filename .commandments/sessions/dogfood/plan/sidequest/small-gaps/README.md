# small-gaps

Each found by using the tool, each small, none urgent.

## Open

**A subagent's writes are attributed to the ORCHESTRATOR's session.** The WriteGate
demanded a declaration for work the orchestrator did not do, and the sin-check sent
it to fix a file a live worker was holding. Obeying either would corrupt a lane's
work in progress.

**A condition superseded by a later ruling has no honest exit.** `met` claims it
holds; `clear` drops the whole gate. Retiring one with its reason is the missing verb
— and marking two `met` when a ruling had superseded them is a small lie already told.

**An ACCEPTED item cannot receive a receipt.** A worker that measured after
acceptance is told "Nobody holds it" — true, and it reads as the worker's mistake
rather than a settled item. Either accept the late receipt or say plainly that the
item is settled and how to reopen it.

**The durable half should say whether it is actually durable.** `orchestrate
show`/`doctor` printing "10 files, 0 tracked" would make the gap between "the profile
exists" and "the profile survives this machine" announce itself — the same shape as
the stranded-board warning.
